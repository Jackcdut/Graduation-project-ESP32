# 🔧 硬件设计资料

本目录包含毕业设计的全部硬件设计资料。

## 📁 目录结构

```
硬件设计/
├── 原理图及PCB/    # 主板设计文件（立创EDA工程）
├── 产品资料/       # 关键芯片数据手册

```

## 🔌 主要芯片清单

| 芯片型号 | 功能描述 |
|---------|---------|
| ESP32-S3 | 主控芯片，WiFi/BLE通信 |
| STM32F407 | 协处理器，高速ADC采集 |
| AD9833 | DDS信号发生器 |
| MCP41010 | 数字电位器 |
| OPA2350 | 高速运算放大器 |
| TLV3502 | 高速比较器 |
| LM5176 | 四开关同步升降压控制器 |
| SCT2432 | 同步降压转换器 |
| SY7208 | 升压转换器 |
| CH224A | USB PD协议芯片 |
