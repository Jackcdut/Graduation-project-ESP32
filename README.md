# ESP32-P4 多功能开发板 - 毕业设计项目

基于 **ESP32-P4 + ESP32-C6 + STM32F407** 三芯片架构的多功能电子测量仪器开发板。

## 🎯 项目简介

本项目是一个集成多种电子测量功能的嵌入式系统，采用 ESP32-P4 作为主控负责 GUI 显示和用户交互，ESP32-C6 提供 WiFi 网络功能，STM32F407 负责高精度模拟信号采集与处理。

### 主要功能

| 功能模块 | 描述 |
|---------|------|
| 📊 示波器 | 双通道数字示波器，支持 FFT 频谱分析、自动测量、波形存储 |
| ⚡ 数控电源 | CC/CV 模式可编程电源，支持 PD 快充输入，过压/过流/过温保护 |
| 🔌 万用表 | 电压/电流/电阻测量，自动量程 |
| 〰️ 信号发生器 | DDS 波形发生器，支持正弦/三角/方波输出 |
| 📡 无线串口 | WiFi 透传功能，支持 TCP/UDP 通信 |
| ☁️ 云平台 | OneNET 物联网平台集成，远程数据监控 |

## 🔧 编译与烧录

### 环境要求

- ESP-IDF v5.3+
- Keil MDK v5 (STM32)
- Python 3.8+

### ESP32-P4 主程序

```bash
# 编译
idf.py build

# 烧录并监控
idf.py -p /dev/ttyUSB0 flash monitor
```

### ESP32-C6 从机程序

```bash
# 编译
idf.py -B build_slave build

# 烧录
idf.py -B build_slave -p /dev/ttyUSB1 flash
```

### STM32F407 固件

使用 Keil MDK 打开 `stm32/MDK-ARM/project.uvprojx` 进行编译和烧录。

## 📡 通信协议

ESP32-P4 与 STM32 之间采用自定义串口协议通信：

```
帧格式: [帧头][功能码][数据长度][数据][校验和]
        0xAA   1字节    2字节    N字节   1字节
```

详细协议定义见 `stm32/BSP/Communication/comm_protocol.h`

## ✨ 功能特性

### 示波器
- 采样率: 最高 1MSPS
- 带宽: DC-500kHz
- 输入范围: ±50V (可调 PGA)
- FFT 频谱分析
- 自动测量 (Vpp, Freq, Duty 等)
- 波形数据导出

### 数控电源
- 输出电压: 0-28V
- 输出电流: 0-3A
- CC/CV 自动切换
- PD 快充输入 (5V/9V/12V/20V/28V)
- 过压/过流/过温保护

### 云平台功能
- OneNET 物联网平台接入
- 实时数据上报
- 远程参数配置
- Web 仪表盘可视化
