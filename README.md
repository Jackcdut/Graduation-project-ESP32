# 🔧 硬件设计资料

本分支包含毕业设计项目的所有硬件设计资料，包括原理图、PCB、芯片手册等。

## 📁 目录结构

```
├── 原理图及PCB/           # 立创EDA工程文件
│   └── MeaLink.eprj2      # 主板原理图和PCB
├── 产品资料/              # 芯片数据手册
│   ├── AD9833.pdf         # DDS信号发生器芯片
│   ├── MCP41010.pdf       # 数字电位器
│   ├── OPA2350.pdf        # 运算放大器
│   ├── TLV3502.pdf        # 高速比较器
│   ├── LM5176.pdf         # 同步降压控制器
│   ├── SY7208.pdf         # 升压转换器
│   ├── SCT2432.pdf        # 降压转换器
│   ├── CH224A.pdf         # PD快充协议芯片
│   └── ...
└── 模板工程/              # 各模块独立原理图
    ├── 示波器.eprj2       # 示波器前端电路
    ├── 万用表.eprj        # 万用表测量电路
    ├── 信号发生器.eprj    # DDS信号发生器
    └── 数控电源.eprj      # CC/CV电源电路
```

## 🔌 主要芯片

| 芯片 | 功能 | 说明 |
|------|------|------|
| AD9833 | DDS信号发生器 | 正弦/三角/方波输出 |
| MCP41010 | 数字电位器 | PGA增益控制 |
| OPA2350 | 运放 | 信号调理 |
| TLV3502 | 比较器 | 频率测量 |
| LM5176 | 电源控制 | 四开关降压升压 |
| CH224A | PD协议 | USB-C快充输入 |
